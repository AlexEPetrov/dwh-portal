### Сборка образа

Подготавливается финальный образ (docker image) с использованием multi-stage сборки.
Предварительный этап выделяется для сборки артефактов, которые далее копируются в финальный образ:
- документация
- миграции Alembic


## Порядок сборки и развертывания

1. Удалить папку _build (если есть) в корне репозитория 

2. Запустить файл _build_docker_all.sh
Результат сборки - в папке _build генерируются файлы:
  ./*.img - финальный docker-образ
  ./migrations/*.sql - файлы миграции - обновление Alembic migrations для развертывания на целевом SQL Server
  ./data - файлы шаблонов, логи и т.п. - файлы для подключения к контейнеру через volumes. 

3. Скорировать сгенерированные файлы на целевой сервер в целевую папку (/srv/).

4. Выставить корректные значения в файле .env

5. На целевом сервере: выполнить setup.sh для загрузки образа, запуска и инициализации сервиса.

6. Проверка готовности сервиса - доступность: http://<host>:<port>/swagger
