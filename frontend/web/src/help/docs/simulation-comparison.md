# Сравнение результатов оценок

Экран `/valuations/simulation/comparison` показывает одновременно до пяти срезов,
добавленных с экрана `/valuations/simulation/analysis` кнопкой **Добавить в сравнение**.

В сравнение также можно добавить deterministic-срез с экрана `/valuations/scenarios`.
Такой срез читается из `run_mode=deterministic` и представляет один результат без
стохастики. Для него сохраняются все представления: **Статистика**, **Распределение**,
**Помесячно**, **Liquidity-at-Risk** и **Raw data**.

В статистике deterministic-срез имеет `COUNT = 1`. Метрики разброса и хвостового
риска (`STD`, `P05`, `P95`, `CVaR95`) не интерпретируются как стохастические оценки
и отображаются прочерком. Графики и таблицы используют тот же layout, что и
симуляционные срезы, но строятся по единственному значению.

## Корзина сравнения

В корзине сохраняются только условия выборки: источник `filter` или `balance`,
`observation_date`, `valuation_type`, сценарий, период, target, структурные фильтры и
Balance tree. Корзина хранится в versioned `localStorage`, поэтому сохраняется после
F5, закрытия вкладки и перезапуска браузера в том же профиле. Результаты API и Plotly
figure не сохраняются и загружаются заново при открытии экрана.

Пункт меню **Сравнение** в левом сайдбаре показывает текущее количество срезов в
корзине: «Сравнение (N)», если корзина не пуста, и просто «Сравнение» иначе.

Допускаются разные даты, разные `valuation_type`, разные source mode и period mode.
Все срезы одной корзины обязаны использовать одну валюту. Точный дубликат условий не
добавляется. Максимальный размер корзины — пять срезов.

Краткое имя формируется автоматически из даты, `valuation_type`, period mode и scope.
Аналитическая идентичность не зависит от имени; модель предусматривает отдельное
`displayName` для будущего пользовательского переименования.

## Представления

- **Статистика** — единая таблица metric × slice; статистика не пересчитывается на frontend.
- **Распределение** — Plotly traces всех срезов на одном графике со стабильными цветами.
- **Помесячно** — одновременное отображение backend monthly figures.
- **Liquidity-at-Risk** — одновременное отображение cumulative cash position figures.
- **Raw data** — отдельная вкладка и таблица для каждого среза.

Данные каждого активного представления читаются параллельно через существующие
Simulation Analysis endpoints. Ошибка одного среза не скрывает успешно загруженные
срезы. Исторический экран `/dashboard/observation-comparison` остаётся отдельным
механизмом сравнения по датам и не изменяется.
